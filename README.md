# defender-of-the-little-ones
Este projeto tem como objetivo desenvolver um aplicativo mobile voltado à proteção e defesa dos animais, oferecendo uma plataforma que permita denunciar casos de agressão, maus-tratos e abandono, além de promover educação, conscientização e engajamento social em prol do bem-estar animal.

🚀 Funcionalidades previstas:

📸 Denúncia anônima ou identificada com envio de fotos, vídeos e localização.

🐶 Cadastro de ONGs, abrigos e protetores independentes.

📍 Mapa interativo com locais de denúncia e pontos de apoio.

📢 Notificações de alertas e campanhas de adoção/resgate.

📚 Sessão educativa sobre direitos dos animais e legislação.

💬 Chat de apoio com ONGs ou redes de voluntários (futuramente).

🛠 Tecnologias sugeridas (modificável conforme seu stack):

Frontend: React Native / Flutter

Backend: Node.js / Firebase / Django REST

Banco de Dados: Firestore / PostgreSQL

API de localização: Google Maps API

Hospedagem: Firebase / Vercel / Heroku
